PL/SQL Scripts

A collection of PL/SQL programs developed and tested using Oracle Database 11g Express Edition (XE).

This repository contains practical examples covering fundamental and intermediate PL/SQL concepts, including anonymous blocks, control structures, cursors, procedures, functions, exception handling, triggers, and database operations.

Environment

The scripts in this repository were developed and tested with:

Oracle Database 11g Express Edition (XE)
Oracle SQL*Plus / SQL Command Line
